Privacy Policy for CutKit 2

Last updated: March 11, 2026

CutKit 2 is an offline utility app for calculating and visualizing optimal rectangular layouts.

Data Collection

CutKit 2 does not require user registration and does not collect personal data for transmission to external servers.

Internet Access

CutKit 2 does not require an internet connection for its core functionality.

Generated Files

The app allows users to export generated results such as PDF and DXF files. These files are created locally on the device and are shared or opened only when the user explicitly initiates such an action.

Third-Party Services

CutKit 2 does not include advertising SDKs, analytics SDKs, or user tracking services in its current version.

Permissions

CutKit 2 is designed to operate without unnecessary device permissions. Export and file sharing are performed using standard Android mechanisms.
